Inspect every published HTTP documentation endpoint and every callable function in the five public native SDK interfaces.

Two surfaces, one source of truth.

The HTTP routes below serve static documentation files from GitHub Pages. They do not call into a running game. Native add-ons use the in-process C ABI documented under Native SDK calls.

HTTP documentation API

Quick start

No authentication · GET only

Begin with discovery, follow the current version into its resource catalog, then cache or consume only the fields your tooling needs.

cURL shell 
curl --fail https://lorexvalkin.github.io/UNBSE/api/index.json
JavaScript js 
const response = await fetch(
  "https://lorexvalkin.github.io/UNBSE/api/index.json"
);
if (!response.ok) throw new Error(response.status);
const discovery = await response.json();
